#  ProjetoPI 2º Semestre - Projeto Acadêmico – Farma7

O Farma7 é um projeto acadêmico desenvolvido com o objetivo de simular um sistema de e-commerce farmacêutico, aplicando na prática conceitos de desenvolvimento front-end e back-end.

O projeto foi criado em grupo durante o semestre, desde a definição do nicho até a estruturação das funcionalidades e da experiência do usuário. A proposta foi desenvolver uma plataforma intuitiva, moderna e funcional para vendas online no segmento de farmácia.

# 📌 Funcionalidades desenvolvidas:
✅ Menu de navegação com categorias organizadas:

- Medicamentos
- Vitaminas
- Beleza
- Higiene
- Promoções

✅ Sistema de listagem de produtos contendo:

- Imagem
- Descrição
- Preço
- Botões de ação

# 💻 Aprendizados principais:
- Estruturar um site com HTML5.
- CSS3 e JavaScript.
- Criar uma experiência de usuário simples e intuitiva.
- Aplicar conceitos de validação e autenticação de usuários.
- Trabalhar em equipe, simulando um projeto real do mercado.
